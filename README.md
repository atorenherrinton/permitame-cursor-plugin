# Permitame for Cursor

Building permit answers for Kitsap County, Washington (unincorporated Kitsap County, Bainbridge Island, Bremerton, Port Orchard and Poulsbo), quoted from official county and city sources. Each answer names the jurisdiction whose code it used and links the source.

## Install

```sh
# Add from the Cursor Marketplace, or use the "Add to Cursor" button at https://permitame.com/#get
```

The first time Cursor uses Permitame, your browser opens so you can sign in at permitame.com. Free accounts include 3 lookups a month; see https://permitame.com/pricing.

## Try

- "Do I need a permit to build a deck in unincorporated Kitsap County?"
- "Do I need a permit to replace my kitchen sink on Bainbridge Island?"

Answers are informational, not legal advice; confirm with the building department before starting work. Permitame is independent and not affiliated with Kitsap County, its cities or any tribe.
